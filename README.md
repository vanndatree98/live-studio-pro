## 🚀 របៀបចាប់ផ្តើមដំណើរការ (Quick Start)

### វិធីទី ១៖ ចុចពីរដង (Double Click) លើឯកសារ
* ចូលទៅកាន់ថត `LIVE YOUTUBE` នៅលើ Desktop
* ចុចពីរដងលើឯកសារ **`start.bat`**
* កម្មវិធីនឹងដំណើរការ Server ហើយបើក Browser ចូលទៅកាន់ `http://localhost:3000` ដោយស្វ័យប្រវត្តិ!

### វិធីទី ២៖ តាមរយៈ Command Line / Terminal
```bash
npm start
```
បន្ទាប់មកបើក Browser ចូលទៅកាន់: [http://localhost:3000](http://localhost:3000)

## 📖 ការណែនាំអំពីមុខងារសំខាន់ៗ

### ១. របៀបផ្សាយផ្ទាល់ YouTube និង Facebook Live

#### ក. ផ្សាយលើ 🔴 YouTube Live (ច្រើនឆានែលព្រមគ្នា - Multi-Channel Live)
1. ចូលទៅកាន់ **YouTube Studio** (`studio.youtube.com`) នៃឆានែលនីមួយៗរបស់អ្នក > ចុច **Go live** > ចម្លងយក **Stream key**។
2. នៅក្នុងកម្មវិធី ចុចប៊ូតុង **⚙️ ការកំណត់ (Settings)** (ឬចុចប៊ូតុង **«📺 ឆានែល»** លើរបារខាងលើ) > ជ្រើសរើសផ្ទាំង **🔴 YouTube Live**។
3. **គ្រប់គ្រងច្រើនឆានែល (Multi-Channel Manager)**៖
   - **ឆានែលទី ១**៖ បិទភ្ជាប់ Stream Key នៃឆានែលចម្បងរបស់អ្នក។
   - **បន្ថែមឆានែលទៀត**៖ ចុចប៊ូតុង **«➕ បន្ថែមឆានែល (Add Channel)»** ដើម្បីបង្កើតឆានែលទី ២, ទី ៣, ទី ៤... រួចដាក់ឈ្មោះសម្គាល់ឆានែល និងបិទភ្ជាប់ Stream Key រៀងៗខ្លួន។
   - **បើក/បិទឆានែល (ON/OFF Toggle)**៖ ឆានែលណាដែលអ្នកបើកកុងតាក់ (ON) នឹងត្រូវផ្សាយផ្ទាល់ ឯឆានែលដែលបិទ (OFF) នឹងមិនត្រូវបានរំខានឡើយ។
4. ចុច **💾 រក្សាទុក (Save Settings)**។
5. នៅលើរបារខាងលើ ចុចប៊ូតុង **🔴 YouTube (X ឆានែល)** រួចចុច **🔴 ចាប់ផ្តើម LIVE** 👉 ប្រព័ន្ធ FFmpeg Tee Muxer នឹងធ្វើការផ្សាយផ្ទាល់ចូលទៅគ្រប់ឆានែលដែលបានបើកព្រមគ្នាតែម្តង!

#### ខ. ផ្សាយលើ 🔵 Facebook Live
1. ចូលទៅកាន់ Facebook ផ្ទាល់ខ្លួន ឬ Page របស់អ្នក រួចចូលទៅ <a href="https://www.facebook.com/live/producer" target="_blank">facebook.com/live/producer</a>។
2. ជ្រើសរើស **Streaming software** > ចម្លងយក **Stream key** របស់ Facebook។
3. នៅក្នុងកម្មវិធី ចុចប៊ូតុង **⚙️ ការកំណត់ (Settings)** > ជ្រើសរើសផ្ទាំង **🔵 Facebook Live** > បិទភ្ជាប់ Stream Key។
4. នៅលើរបារខាងលើ ចុចរើសយកប៊ូតុង **🔵 Facebook** រួចចុច **🔵 ចាប់ផ្តើម LIVE**!

#### គ. ផ្សាយលើ 🔥 ទាំង YouTube និង Facebook ព្រមគ្នា (Dual Multi-Stream)
1. បញ្ចូល Stream Key ទាំង YouTube និង Facebook ក្នុងផ្ទាំង **Settings**។
2. នៅលើរបារខាងលើ ចុចរើសយកប៊ូតុង **🔥 Dual (YT+FB)**។
3. ចុច **🔥 ចាប់ផ្តើម LIVE (YT + FB)** 👉 វីដេអូ និងសម្លេងនឹងត្រូវបញ្ជូនទៅកាន់ទាំងពីរវេទិកាក្នុងពេលតែមួយដោយស្វ័យប្រវត្តិ!

### ២. មុខងារផ្ទុកវីដេអូច្រើនភាគ & ទម្រង់ផ្តេក/បញ្ឈរស្វ័យប្រវត្តិ (Multi-Episode Video Playlist)
- **📂 ផ្ទុកវីដេអូច្រើនភាគ (Multi-Episode Video Playlist)**៖
  - នៅត្រង់ប្រអប់ **ប្រភពវីដេអូ (Video Source)** ជ្រើសរើស **"📂 ផ្ទុកវីដេអូពីកុំព្យូទ័រ"**
  - ចុចលើ **"📂 ផ្ទុកវីដេអូច្រើនភាគ (Add Episodes)"** ដើម្បីជ្រើសរើសឯកសារវីដេអូច្រើនក្នុងពេលតែមួយ (`.mp4`, `.webm`, `.mkv`, `.mov`)
  - **ប៊ូតុងបញ្ជាចាក់វីដេអូ (Playback Controls)**៖
    - **⏮️ ភាគមុន (Previous Episode)**៖ ត្រឡប់ទៅចាក់ភាគមុនភ្លាមៗ
    - **⏪ ថយ 10វិ (-10s)**៖ រំកិលថយក្រោយ ១០ វិនាទី
    - **▶️ / ⏸️ ចាក់ / ផ្អាក (Play / Pause)**៖ បញ្ជាចាក់ ឬផ្អាកវីដេអូ
    - **⏩ ទៅមុខ 10វិ (+10s)**៖ រំកិលទៅមុខ ១០ វិនាទី
    - **⏭️ ភាគបន្ទាប់ (Next Episode)**៖ ផ្លោះទៅចាក់ភាគបន្ទាប់ភ្លាមៗ
    - **របាររំកិល Timeline (Scrubber)** និងនាឡិការាប់ពេលវេលា

  - អាចប្តូរទៅប្រើ **"🔄 ចលនាស្វ័យប្រវត្តិតាមធម្មជាតិ (Simulation)"** ឬ **"✏️ កំណត់ដោយដៃ (Manual & Quick Bump)"** បានគ្រប់ពេលវេលា ប្រសិនបើចង់ធ្វើតេស្តសាកល្បងដោយមិនចាំបាច់មាន Internet។

## 💻 របៀបបើក និងដំណើរការលើកុំព្យូទ័រផ្សេងៗ (Run on Other Computers)

លោកអ្នកអាចដំណើរការកម្មវិធីនេះលើកុំព្យូទ័រផ្សេងៗបានយ៉ាងងាយស្រួលតាម ២ របៀប៖

### វិធីទី ១៖ ចម្លង (Copy) ថតកម្មវិធី យកទៅបើកលើកុំព្យូទ័រផ្សេង (Standalone / Portable)
1. **ចម្លងថតកម្មវិធី**៖ Copy ថត `LIVE YOUTUBE` នេះទាំងមូល ដាក់ចូល **Flash Drive (USB)** ឬបង្ហោះទៅ **Google Drive**។
2. **ដាក់លើកុំព្យូទ័រថ្មី**៖ Paste ថតនេះលើ Desktop នៃកុំព្យូទ័រថ្មី។
3. **ចុចបើក `start.bat`**៖
   - ប្រសិនបើកុំព្យូទ័រថ្មី **មិនទាន់មាន Node.js** នោះ `start.bat` នឹងបង្ហាញសារប្រាប់ និងបើកគេហទំព័រ [nodejs.org](https://nodejs.org/) ឱ្យទាញយកដោយស្វ័យប្រវត្តិ (ទាញយកកំណែ LTS រួចដំឡើងតាមធម្មតា)។
   - ប្រសិនបើ **មិនទាន់មាន folder `node_modules`** នោះ `start.bat` នឹងដំណើរការដំឡើង Library ស្វ័យប្រវត្តិតាមរយៈ `npm install` ដោយមិនបាច់វាយ Command អ្វីទាំងអស់។
   - បន្ទាប់មក កម្មវិធីនឹងបើកផ្ទាំង Studio លើ Browser `http://localhost:3000` ភ្លាមៗជាការស្រេច!

### វិធីទី ២៖ បើកបញ្ជាពីចម្ងាយ តាមរយៈកុំព្យូទ័រ ឬទូរស័ព្ទផ្សេងក្នុង Wi-Fi / LAN តែមួយ (Remote Access via LAN / Wi-Fi)
អ្នកមិនចាំបាច់ Copy កម្មវិធីទៅកុំព្យូទ័រផ្សេងទេ! អ្នកអាចទុកកម្មវិធីឱ្យដំណើរការលើកុំព្យូទ័រមេ (Host PC) ហើយប្រើប្រាស់កុំព្យូទ័រ Laptop ផ្សេង ឬទូរស័ព្ទ/iPad ដើម្បីចូលទៅមើល និងបញ្ជា Live បាន៖

1. នៅលើកុំព្យូទ័រមេ ចុចបើក **`start.bat`**។
2. ក្រឡេកមើលផ្ទាំង Command Prompt ខ្មៅ វានឹងបង្ហាញអាសយដ្ឋាន IP លើ Network ដូចជា៖
   ```text
   📱💻 លើកុំព្យូទ័រផ្សេង / ទូរស័ព្ទ / iPad (ក្នុង Wi-Fi/LAN តែមួយ):
      👉 http://192.168.0.110:3000  (Ethernet ឬ Wi-Fi)
   ```
3. យកកុំព្យូទ័រផ្សេង ឬទូរស័ព្ទដៃដែលភ្ជាប់ Wi-Fi ជាមួយគ្នា រួចបើក Google Chrome ឬ Microsoft Edge ហើយវាយបញ្ចូលអាសយដ្ឋាននោះ (ឧទាហរណ៍៖ `http://192.168.0.110:3000`)។
4. **ប្រសិនបើកុំព្យូទ័រផ្សេងបើកមិនចេញ (ជាប់ Firewall)**៖
   - នៅលើកុំព្យូទ័រមេ សូមចុចកណ្ដុរស្ដាំ (Right-Click) លើឯកសារ **`allow-firewall.bat`**
   - ជ្រើសរើស **"Run as administrator"** (ដំណើរការជា Admin)
   - នោះ Windows Firewall នឹងបើកអនុញ្ញាត Port 3000 ភ្លាមៗ ហើយកុំព្យូទ័រផ្សេងៗនឹងអាចចូលប្រើប្រាស់បាន ១០០%!

## ⚡ គន្លឹះដោះស្រាយ និងការពារកុំឱ្យវីដេអូ Live ទាក់ៗ (Smooth Streaming Guide)

ប្រសិនបើលោកអ្នកជួបប្រទះបញ្ហា **វីដេអូ Live ទាក់ៗ, គាំង ឬ Buffer** នៅលើ YouTube ឬ Facebook សូមអនុវត្តតាមការណែនាំដូចខាងក្រោម៖

### ១. មូលហេតុចម្បងដែលបណ្តាលឱ្យ Live ទាក់
1. **ល្បឿន Internet Upload មិនគ្រប់គ្រាន់**៖ នៅពេលផ្សាយផ្ទាល់ច្រើនកន្លែង (Multi-Stream YouTube + Facebook) តម្រូវការ Upload នឹងកើនឡើង។
   - *ឧទាហរណ៍*៖ បើជ្រើសរើស Bitrate 3500 kbps ពេល Live ទាំងពីរ នោះតម្រូវការ Internet គឺប្រហែល 7 Mbps Upload ជាប់លាប់។
2. **កម្លាំង CPU ម៉ាស៊ីនឡើងខ្ពស់ (100% CPU)**៖ នៅពេល Browser និង FFmpeg ដំណើរការស្របគ្នា។

### ២. ដំណោះស្រាយដែលកម្មវិធីបានបង្កើនប្រសិទ្ធភាពរួចជាស្រេច (Built-in Optimizations)
- 🚀 **Hardware H.264 GPU Acceleration**៖ Browser ប្រើប្រាស់ GPU (NVIDIA, Intel QuickSync, AMD) ដើម្បី Encode វីដេអូ ដោយមិនស៊ីកម្លាំង CPU ច្រើនឡើយ។
- ⏱️ **Frame Pacing & Throttling**៖ ផ្ទៃ Canvas ត្រូវបានកម្រិតឱ្យដំណើរការត្រឹម 30 FPS / 60 FPS ជាក់លាក់ ដោយមិនខ្ជះខ្ជាយ CPU/GPU លើអេក្រង់ 120Hz/144Hz ឡើយ។
- 💨 **Offscreen Blur Pipeline**៖ ផ្ទាំង Background Blur និង Beauty Filter ត្រូវបានកែច្នៃឱ្យដំណើរការលើ Offscreen Canvas តូច រួចពង្រីកឡើងវិញ ដែលបង្កើនល្បឿន Render បានលឿនជាងមុន 5x ទៅ 10x ដង។
- ⚡ **FFmpeg Ultrafast Preset & Dynamic Buffer**៖ ម៉ាស៊ីនបំប្លែងវីដេអូ FFmpeg ប្រើប្រាស់ Preset `ultrafast` រួមជាមួយ Buffer ទំហំសមាមាត្រ Bitrate ជួយឱ្យការបញ្ជូនទិន្នន័យទៅ YouTube/Facebook មានស្ថេរភាពខ្ពស់បំផុត។

### ៣. ការកំណត់ដែលត្រូវបានណែនាំ (Recommended Settings)
- **សម្រាប់ Internet ទូទៅ ឬពេល Live ច្រើនឆានែលព្រមគ្នា**៖

- **សម្រាប់កុំព្យូទ័រខ្លាំង និង Internet Upload លើសពី 15 Mbps**៖
  - គុណភាព (Quality)៖ **1080p (30 FPS)**
